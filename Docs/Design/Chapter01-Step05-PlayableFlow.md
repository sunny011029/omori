# 第一章第五步：清扫、再生、柜中奇遇

日期：2026-10-24。用户已授权本步骤，并明确本轮按四处清扫任务达到 100%，保留所有桌椅位置。

## 本段可玩流程

1. 在学校完成四处普通任务，每处 25%：左教室、右教室、走廊的杂物，以及右下角原有的散落书本。书本提示为“整理这些书本”；完成后只隐藏该组地面书本，保留旁边的大书柜。
2. 达到 100% 后走向学校下方出口，触发一次异常，三个标注再生点出现纸团。反复交互始终显示“无法清理”，不会清除纸团或重复增加进度。
3. 查看纸团后，去左侧四连柜的第三个柜子找工具，开启后遇见抹茶云。读完对话才解锁右侧大书柜左边的独立入口柜；中途退出可重新交谈。
4. 从独立柜子进入 MochaStore。与柜台上的抹茶云交谈，获得云视使用说明；查看其右侧制作台，提示缺少“微涩的抹茶粉”，不能提前制作。
5. 从甜品店左侧过道里的绿色入口返回学校。清扫、看画本许可和剧情状态保留，可以按 Q 查看三位 NPC 上方的灰云。

异常采用“一次离校尝试触发三个点”的本轮实现，没有加入反复清扫再生物的循环，也没有加入未指定位置的摆椅任务。

## 操作与存档

- WASD / 方向键：移动；靠近目标按 E 或点交互提示。
- 对话用数字键或鼠标选择；只有一个选项时也支持 E / Enter；Esc 退出当前对话。
- 解锁后按 Q 开关云视。
- 非对话时按 Esc 打开菜单，可继续游戏或经过二次确认重新开始本章。
- 完成任务、取得许可、完成关键对话和场景切换时自动保存。退出后从保存的场景继续；位置使用安全入口，不保存任意站立点。
- 正式存档位于 Unity `Application.persistentDataPath/MatchaCloud/chapter01.json`，保留前一份 `.bak`。测试使用项目 `Temp/ChapterOneTests` 的隔离存档。
