# 第九步：分享甜品与第一章结局

## 本轮确认范围

- 只实现接受分享的主线。邀请时可先离开，之后继续；暂不实现拒绝分享分支。
- 保留原有 3 处再生纸团的位置，清理后只结算“sheila 关联区域”。常规清扫仍为之前的 4 项。
- 恢复同一条“把教室打扫干净”清单项作为章末伏笔；不启动第二章。完成后可自由探索、回看记录与结尾。

## 可玩顺序

1. 带着第八步做好的马卡龙回学校，在 sheila 身边按 E，选择递上便携盒。她按已保存的甜度和辅料回应。九种组合均能完成故事。
2. 她说第一版也没有那么差。两句回应都尊重她的决定：“那你想不想再看看第一版？”或“你也不用现在就决定。”
3. sheila 自己决定留下草稿。画面展示草稿滑入画本、手压平纸页，动作完成后才关闭再生联系。中途退出会保留待播放节点。
4. 抹茶云：“诶？云怎么还在？”女主：“可是……纸团好像不再出现了。”灰云和细雨保留。
5. 玩家亲自去原来 3 处纸团的位置按 E 收起残留画纸。拾取直接移除纸团、保存并更新顶部进度，不弹框、不锁定移动。草稿仍是 sheila 的私人物品，不属于清扫目标。
6. 关联区域达到 100%，收录抹茶马卡龙食谱及本次口味，更新人物记录。顶部提示“局部清扫完成 · 回去与 sheila 交谈”。回到她身边交谈后进入结算与章末清单；出口不再推进或重播结尾。其他两位同学的甜品仍未解锁。
7. 女主划掉“把教室打扫干净”，合上记事本；同一条事项悄悄恢复。展示第一章结尾，随后可自由探索。

## 记录与存档

- I：成品分享后数量为 0，不会因为切场景或重开对话再次赠送。
- J：原有 6 页调查记录保留；草稿收好后增加 sheila 近况和甜品收藏入口。人物记录只写观察到的事实，明确她仍担心比赛、灰云仍在。
- `craftStage=Packed` 保留为制作历史，`dessertConsumed` 单独记录实际消耗。
- `endingStage` 区分品尝、回想、待收好草稿、云仍在、最后清扫、待播放清单与章节完成。
- 收好草稿与章末清单都要实际播放完才提交完成节点。中途离开或关闭游戏可以重播未完成节点。
- 逐处清扫保存 `finalPaperMask`；只有 3 处全部完成才收录食谱。食谱解锁派生自保存状态，不重复发放物品。
- 旧版第一章存档可继续。写入失败时，分享、草稿、清扫与章节完成会恢复到上一步。
