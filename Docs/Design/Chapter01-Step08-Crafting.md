# 第八步：第一份抹茶马卡龙

用户确认：sheila 的第一份甜品固定为抹茶马卡龙，保留三种甜度和三种辅助食材，共 9 种组合。所有口味都能继续故事，不评分，不设正确配方或失败惩罚。此决定替代旧策划“曲奇／小蛋糕”两种基底；其余三款甜品与人物对应不变。

## 试玩入口与操作

第七步领取“微涩的抹茶粉”后，通过学校柜门回到甜品店，靠近抹茶云右侧的现有制作台，按 E。

1. 选择低甜、均衡或高甜。
2. 选择牛奶、红豆或不添加。基础食材由店内提供，不另开购买或收集任务。
3. 查看配方并明确加入一份微涩的抹茶粉。加入之前可以重新选口味。
4. 搅拌三次，每次按 1 或点击“搅拌一次”。界面显示次数与进度。
5. 选择开始烘焙，短暂等待约 3 秒。烤好后保持待取，没有超时、烤焦或惩罚。
6. 选择“装盘并放入便携盒”，得到一份抹茶马卡龙。I 物品栏显示成品、数量及已选口味。

数字键或鼠标选择。Esc 可以随时关闭制作界面，再次交互从保存的步骤继续。对话打开时锁定移动，关闭后恢复。烘焙时可离开制作台、往返场景或退出游戏，回来后继续装盒。

## 原料与存档

- `powderCollected` 保留为历史领取标记，避免用掉后在学校再次出现。
- 加入前物品栏显示一份抹茶粉；加入后显示留在店内的制作中甜品；装盒后只显示一份便携甜品。
- 同一份原料只有一个制作状态。中断不会扣掉原料再创建一份，新开制作、重复加料、超额搅拌、提前装盒和重复装盒均被拒绝。
- 每个确认步骤保存 `craftStage`、`sweetness`、`filling`、`stirCount`、`bakeReadyUtcTicks`。保存采用现有临时文件与原子替换机制；写入失败则制作步骤回退，允许稍后重试。
- 对 Windows 偶发的文件占用，最多短暂重试两次（各 25 毫秒），仍失败则保留上一步并提示。模拟持续写入失败已验证不会发放成品或损失制作中的原料。
- 烘焙保存 UTC 完成时间，正常退出后时间继续经过；烤好仍须明确装盒。无逐帧写盘。
- 旧存档缺少制作字段时默认为尚未开始。非法制作状态链回退有效备份。重新开始本章会重置制作状态。

## 范围与衔接

本步使用第七步已有的抹茶马卡龙 Sprite，增加制作界面与运行时逻辑；学校、甜品店场景文件、地板、桌椅、碰撞、人物与摄像机设置均不需要修改。

带给 sheila 品尝、根据配方回应、她自主保留最初草稿、停止再生与最后清扫属于后续步骤。此时制作不会清除灰云、让再生画纸可清理，也不会提前解锁 Elaine 或 nate 的甜品。第一份甜品及口味已存档，供下一步读取；四款甜品资料表仍只有起始抹茶蛋糕标记为起始可用。
