## 1. 已确认的规则修订

1. 特殊原料统一称为 **微涩的抹茶粉**。后续对白、任务、物品栏、配方和存档标识均围绕同一原料，不再混用“抹茶露”。
2. **再生垃圾出现后直接显示“无法清理”**。异常调查阶段的交互不移除垃圾、不增加清洁度、不发重复奖励。普通垃圾仍然可清理。
3. 初遇抹茶云的柜子与甜品店入口柜是两扇不同的柜门，位置见下表。

沿用既有策划的后段因果：调查与交流 → 获得原料 → 制作并分享甜品 → 小雨主动保留草稿 → 异常停止再生 → 玩家清理剩余废纸。灰云仍在。异常稳定后的最终清扫仍需可用，不能把“无法清理”做成永久不可清理。

旧版“清完一轮再生垃圾、再次达到 100%，才能继续”的前置条件作废。是否仍保留两轮门口演出及三个再生点的具体触发次序，尚未在本轮指定，后续细化时确认，不自行增加无限再生。

## 5. 已明确的流程约束

普通清扫 → 达成当前常规清扫目标 → 异常再生、交互显示“无法清理” → 引导寻找工具 → 在指定初遇柜遇见抹茶云 → 指引最右侧入口柜 → 进入甜品店 → 返回学校开展云视调查。
