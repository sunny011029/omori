# 第一章第六步：云视调查与线索记录

日期：2026-10-24。用户授权本步，并要求遇到剧情逻辑或未明确细节时及时提出。

## 调查范围

依据策划第 5–6 页，调查前三类线索可以自由探索，私人画本必须先获得小雨许可。两位背景同学只提供日常观察，不作为主线门槛。本步结束在准备与小雨深入交谈；不实现后续的核心问答、最初草稿、原料凝结、制作或异常解除。

四条关键线索：

1. 再生画纸：开启 Q 云视，在任意一个再生点选择观察笔触并记下，发现画纸似乎来自同一幅作品。三个点共享这条线索，不重复计数。
2. 课桌与灰云：在云视下观察小雨，或从她的课桌菜单观察，记录灰云与纸张之间的微弱联系。观察桌边公开可见的现象不会翻看私人画本，也不会自动授予许可。
3. 公开比赛通知：阅读“家”的比赛主题以及提交日期临近的信息，确认后记入记录。不虚构具体截止日期。
4. 小雨的画本：先请求许可，再查看两页；第二页选择合上并记下线索。看一页或按 Esc 退出，不记录完整阅读。

四条线索可以不同顺序取得。全部记录后显示调查小结，引导回到小雨身边；不能以线索代替她表达内心，也不会提前发放“微涩的抹茶粉”。灰云和三个再生点仍然存在，再生点继续显示“无法清理”。

## 操作与反馈

- Q 切换云视；观察 NPC 的菜单同时保留日常交谈。
- J 开关调查记录；记录包含总览、四条线索详情和一页可选同学近况。未知线索只显示探索方向。
- E 交互；数字键或鼠标选择；Esc 退出面板。阅读期间角色停止移动，关闭后恢复。
- 调查开启后，HUD 显示四条调查线索的进度，不继续把清扫 100% 当作当前任务。
- 两个场景都能查看记录；完成线索即自动保存。切换场景和重新进入游戏都应保留记录与许可。
- 已认识抹茶云后，再生点不再引导找工具；甜品店提示随制作台查看和调查完成状态更新。
